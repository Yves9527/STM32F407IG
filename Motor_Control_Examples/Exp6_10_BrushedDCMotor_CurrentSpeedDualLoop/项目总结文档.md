# 直流有刷电机电流+速度双环 PID 控制实验 —— 项目总结文档

## 一、项目概述

本项目是**正点原子（ALIENTEK）F407 电机开发板**上的嵌入式例程，名称为“**直流有刷电机电流+速度双环 PID 控制**”。项目基于 **STM32F407IGT6** 单片机，实现对带霍尔编码器的直流有刷电机的高精度闭环调速控制：

- 通过**编码器测速**获得电机实际转速；
- 通过**电流采样（ADC+DMA）**获得电机实际电流；
- 采用**速度环（外环）+ 电流环（内环）**的串级双闭环 PID 结构，将速度环的输出作为电流环的目标电流；
- 使用 **TIM1 互补 PWM（带死区）**配合 H 桥驱动板控制电机的转速与转向；
- 通过 **LCD** 实时显示目标速度、实际速度、实际电流与 PWM 占空比；
- 通过 **串口 1** 与上位机“PID 调试助手”通信，可在线整定 PID 参数、下发启停/刹车指令并观察波形。

> 文档配套代码来自正点原子官方例程，版权归属于广州市星翼电子科技有限公司（正点原子），本文件仅作为工程理解与维护参考。

## 五、系统初始化流程

`main()` 中的初始化顺序（`main.c`）：

| 步骤 | 函数 | 说明 |
| --- | --- | --- |
| 1 | `HAL_Init()` | 初始化 HAL 库 |
| 2 | `sys_stm32_clock_init(336,8,2,7)` | 配置系统时钟 168 MHz |
| 3 | `delay_init(168)` | 延时初始化 |
| 4 | `usart_init(115200)` | 串口 1，上位机调试 |
| 5 | `led_init()` / `lcd_init()` / `key_init()` | LED、LCD、按键 |
| 6 | `pid_init()` | PID 参数初始化 |
| 7 | `atim_timx_cplm_pwm_init(8400-1, 0)` | TIM1 互补 PWM，周期 50 μs（约 20 kHz） |
| 8 | `dcmotor_init()` | 电机初始化（SD 引脚、方向、速度） |
| 9 | `gtim_timx_encoder_chy_init(0xFFFF, 0)` | TIM3 编码器接口，84 MHz 计数 |
| 10 | `btim_timx_int_init(1000-1, 84-1)` | TIM6 基本定时器，1 ms 中断 |
| 11 | `adc_nch_dma_init()` | ADC 多通道 + DMA 采样 |
| 12 | `debug_init()`（可选） | 上位机调试初始化，上传电机类型、状态与 PID 参数 |

初始化完成后，进入主循环 `while(1)`：

- 扫描按键：KEY0 目标速度 `+50`（上限 +300，正转）；KEY1 目标速度 `-50`（下限 -300，反转）；KEY2 停机并重置 PID；
- 每 200 ms 刷新一次 LCD 显示并翻转 LED0；
- 每 10 ms 主循环延时一次；
- 开启调试时，循环内接收上位机设定的 PID 参数与控制指令。

## 六、关键模块详解

### 6.1 定时器模块 `Drivers/BSP/TIMER/dcmotor_tim.c`

#### TIM1 互补 PWM（电机驱动）

- 使用 **PWM 模式 1**，主通道 PA8（CH1）、互补通道 PB13（CH1N）；
- 自动重装载值 `ARR = 8399`（`8400-1`），预分频 `PSC = 0`；
- 计数频率 168 MHz，PWM 周期 = `8400 / 168M = 50 μs`，即 **20 kHz**；
- 配置了**死区时间** `DeadTime = 0x0F`，并设置 OSSR/OSSI、关闭 BKIN 刹车检测；
- 通过 `dcmotor_dir()` 切换主通道或互补通道输出来控制正反转。

#### TIM3 编码器接口（测速）

- 复用为编码器模式 `TIM_ENCODERMODE_TI12`（TI1/TI2 双沿检测，**4 倍频**）；
- 输入滤波器设置 `IC1Filter/IC2Filter = 10`，用于滤除编码器抖动；
- 计数器 `ARR = 0xFFFF`（65535），计数溢出由 `TIM3_IRQHandler` 中的更新中断统计，合成 32 位总计数；
- 编码器分辨率：11 线 × 4 倍频 = **44**（`ROTO_RATIO`），减速比 **30:1**（`REDUCTION_RATIO`）。

#### TIM6 基本定时器（1 ms 控制节拍）

- `PSC = 83`，`ARR = 999`，定时 1 ms；
- 中断服务 `BTIM_TIMX_INT_IRQHandler()` 触发 `HAL_TIM_PeriodElapsedCallback()`；
- 编码器测速每 5 ms 计算一次；PID 双环控制按采样周期 `SMAPLSE_PID_SPEED = 50 ms` 执行。

### 6.2 电机驱动模块 `Drivers/BSP/DC_MOTOR/dc_motor.c`

- `dcmotor_init()`：初始化 SD 停止引脚（PF10/PF2）为推挽输出，默认关闭输出；
- `dcmotor_start() / dcmotor_stop()`：拉高/拉低 SD 引脚开启/关闭 H 桥；
- `dcmotor_dir()`：通过切换 PWM 主/互补通道控制方向；
- `motor_pwm_set()`：根据参数的符号决定方向，绝对值决定比较值（占空比），正数正转、负数反转；
- `speed_computer()`：编码器测速，采用**中位值平均滤波（排序取中 6 个平均）+ 一阶低通滤波（q=0.48）**；
- `calc_adc_val()`：对电压、温度、电流三个通道的 ADC 原始值求平均滤波。

### 6.3 PID 模块 `Drivers/BSP/PID/pid.c`

- 支持**位置式 / 增量式**两种 PID，由宏 `INCR_LOCT_SELECT` 选择（本实验使用位置式，取 0）；
- `PID_TypeDef` 结构体含目标值、实际值、误差累计、P/I/D 系数及误差历史；
- `increment_pid_ctrl()`：执行一次 PID 计算并返回输出；
- `integral_limit()`：对累计误差（积分项）做限幅，防止积分饱和。

#### 默认 PID 参数（位置式）

| 环路 | KP | KI | KD | 积分限幅 |
| --- | --- | --- | --- | --- |
| 速度环（外环）S | 1.500 | 0.023 | 0.002 | ±7000 |
| 电流环（内环）C | 1.000 | 3.750 | 0.000 | ±2500 |

> 若切换为增量式（`INCR_LOCT_SELECT=1`），电流环 KI 默认 3.00。可通过上位机调试助手在线整定上述参数。

### 6.4 ADC 电流采集模块 `Drivers/BSP/ADC/adc.c`

- ADC1 多通道扫描 + 连续转换，3 个通道（电压/PB1、温度/PA0、电流/PB0），12 位分辨率；
- 使用 **DMA2 Stream4，通道 0，循环模式**，外设到内存半字传输；
- 单个通道连续采样次数 `ADC_COLL = 1200`，`HAL_ADC_ConvCpltCallback()` 中计算均值并做一阶低通滤波：
  - 电流换算系数 `ADC2CURT = 3.3 / 4.096 / 0.12`（单位：mA / 计数）；
  - 先采集 16 次平均作为“初始参考电流”，用于抵消零漂；
  - 电流 < 20 mA 视为无效，置 0。

### 6.5 显示与交互模块

- `lcd_dis()`：显示 PWM 占空比、目标速度（RPM）、实际速度（RPM）、实际电流（mA）；
- 按键逻辑集中在 `main.c` 主循环；
- LED0 每 200 ms 翻转一次作为运行指示。

## 七、双闭环 PID 控制原理

双闭环采用**串级（级联）控制**结构：

```
                ┌──────────────────────────────────────────────┐
目标速度 ──► [速度环 PID(外环)] ──► 目标电流 ──► [电流环 PID(内环)] ──► PWM占空比 ──► 电机
                │                                                │
                 ◄──── 实际速度(编码器测速)                       ◄──── 实际电流(ADC采样)

速度环输出 = 目标电流（作为电流环的 SetPoint）
电流环输出 = PWM 比较值（0 ~ 8200，ARR=8400）
```

控制流程（在 `HAL_TIM_PeriodElapsedCallback()` 中，每 50 ms 执行一次）：

1. 对速度环、电流环积分限幅；`integral_limit` 分别限幅 ±7000、±2500；
2. **速度环**：`increment_pid_ctrl(&g_speed_pid, 实际速度)` 得到输出（视为目标电流）；
3. 根据速度环输出符号设置电机方向（正/反转），并取绝对值作为目标电流；
4. 目标电流上限限幅为 **200**（mA）；
5. **电流环**：将目标电流设为 `g_current_pid.SetPoint`，`increment_pid_ctrl(&g_current_pid, 实际电流)` 得到 PWM 比较值；
6. 电流环输出限幅 **0 ~ 8200**（负输出滤为 0，上限避免占空比溢出）；
7. `dcmotor_speed()` 写入 TIM1 比较寄存器，输出 PWM 控制电机；
8. 开启调试时，同步上传实际速度与目标速度的波形数据。

这样，速度环保证转速稳定，电流环快速响应负载变化并限制电流，达到电流、速度双重稳定控制。

## 八、上位机调试协议（串口）

调试层位于 `Middlewares/DEBUG/debug.c/h`，通过串口 1 与“PID 调试助手”通信：

- 波特率 **115200**；
- 帧头 `0xC5`、帧尾 `0x5C`，可选 CRC 校验（`EN_CRC`）；
- 开发板 → 上位机：上传电机类型、状态、速度、电流、PID 参数、波形数据（`debug_send_*`）；
- 上位机 → 开发板：接收/设置 PID 参数（`debug_receive_pid`）、下发控制指令（`debug_receive_ctrl_code`：运行/刹车）；
- 通过宏 `DEBUG_ENABLE` 控制是否启用，`debug_set_point_range(300,-300,300)` 设置目标速度的调节范围，避免电流环目标突变过大。

> 调试时上位机波特率必须设为 115200，且程序默认使用了 “USB_TTL” 转串口接口。

## 九、构建与烧录

### 9.1 构建工具链

- CMake ≥ 3.20；
- ARM 交叉编译器：`arm-none-eabi-gcc`；
- 目标 MCU：Cortex-M4，`-mfpu=fpv4-sp-d16 -mfloat-abi=hard`；
- C 标准 C11，C++ 标准 C++14。

### 9.2 CMake 构建要点（`CMakeLists.txt`）

- 工程名 `atk_f407`；
- 源码通过 `file(GLOB_RECURSE ...)` 自动收集 `User`、`Middlewares`、`Drivers/SYSTEM`、`Drivers/BSP`、HAL 库及启动文件；
- 自动排除 `lcd_ex.c` 及所有 `*_template.c` 模板文件；
- 链接脚本 `STM32F407IGTx_FLASH.ld`，使用 `--gc-sections` 裁剪无用段，`nano.specs / nosys.specs` 最小化标准库；
- 编译完成后生成 `.elf/.hex/.bin` 及 `.map` 映射文件。

```
cmake -S . -B build
cmake --build build
```

生成的 `build/atk_f407.hex`（或 `.bin`）可通过 ST-Link/J-Link、串口等工具烧录至 STM32F407IGT6。

## 十、实验现象与使用说明

### 10.1 实验现象

1. LED0（红灯）每 200 ms 翻转一次，指示程序运行；
2. 按 KEY0 增大目标速度（每按一次 +50，上限 +300，正转）；按 KEY1 减小目标速度（每按一次 -50，下限 -300，反转）；按 KEY2 停止电机并重置 PID；
3. 屏幕实时显示：PWM 占空比、目标速度（RPM）、实际速度（RPM）、实际电流（mA）；
4. 开启调试时，上位机可实时观察速度波形、在线整定 PID 参数并下发启停/刹车指令。

### 10.2 注意事项

- 请使用 USB-TTL 串口，且波特率与上位机保持一致（115200）；
- 本例程仅支持 MCU 屏，不支持 RGB 屏；
- 电源电压需按规定连接，注意电机旋转/停止造成的机械震动；
- **开发板上电或复位后需等待约 2 秒，待电流稳定后再按按键启动**；
- 双环控制中外环（速度环）PID 参数调节幅度不宜过大，否则对整个控制曲线影响较大。
