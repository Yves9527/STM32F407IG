# 项目总结文档

## 一、项目概述

- **项目名称**：直流有刷电机——电流环 + 位置环 双环 PID 控制实验
- **实验编号**：Exp6_9（正点原子 F407 电机开发板）
- **开发平台**：正点原子 STM32F407 电机开发板（MCU：STM32F407IGT6）
- **芯片资源**：Cortex-M4，主频 168 MHz；Flash 1 MB；RAM 128 KB + CCM RAM 64 KB
- **核心功能**：通过「外环位置 PID → 目标电流」+「内环电流 PID → PWM 占空比」的双闭环结构，实现直流有刷电机的精确定位控制。
- **开 发 者**：广州市星翼电子科技有限公司（正点原子 / ALIENTEK）
- **版本 / 日期**：V1.0，2021-10-16（后经本地多次优化提交）

> 本项目为开源电机控制教学例程，主循环、定时器中断写法等已在本地代码仓库中做过优化（详见 `git log` 历史提交）。

---

## 二、实验目的

1. 掌握直流有刷电机的 H 桥 PWM 驱动原理（互补输出 + 死区控制）。
2. 掌握基于编码器反馈的电机位置/速度检测方法。
3. 理解双闭环 PID 结构：外环位置环输出作为内环电流环的给定。
4. 掌握增量式/位置式 PID 算法，以及正负方向控制与输出限幅。
5. 学会使用 ADC + DMA 采集电流/电压/温度，并结合上位机 PID 调试助手调参。

## 四、软件架构

项目采用标准 STM32 HAL 库 + CMSIS 结构的裸机（前后台）程序，由 CMake + arm-none-eabi-gcc 交叉编译。

```
User/                     应用层（main、中断）
Middlewares/DEBUG/        上位机调试通讯（串口协议 + CRC16）
Drivers/SYSTEM/           基础驱动（sys/usart/delay）
Drivers/BSP/              板级外设驱动（LED/KEY/LCD/ADC/DC_MOTOR/PID/TIMER）
Drivers/STM32F4xx_HAL_Driver/    ST 官方 HAL 驱动库
Drivers/CMSIS/            Cortex-M4 内核与设备支持库
STM32F407IGTx_FLASH.ld    链接脚本（Flash/RAM/CCM 内存分配）
CMakeLists.txt            构建脚本
```

**启动流程**（`main.c`）：

1. `HAL_Init()` —— HAL 库初始化
2. `sys_stm32_clock_init(336,8,2,7)` —— 系统时钟 168 MHz
3. `delay_init(168)` —— 延时初始化
4. `usart_init(115200)` —— 串口 1（上位机调试）
5. `led_init() / lcd_init() / key_init()` —— 板载外设
6. `pid_init()` —— PID 参数初始化
7. `atim_timx_cplm_pwm_init(8400-1, 0)` —— TIM1 互补 PWM（20 kHz）
8. `dcmotor_init()` —— 电机初始化（默认正转、速度 0）
9. `gtim_timx_encoder_chy_init(0xFFFF, 0)` —— TIM3 编码器接口
10. `btim_timx_int_init(1000-1, 84-1)` —— TIM6 定时中断（1 ms）
11. `adc_nch_dma_init()` —— ADC + DMA 采集
12. `debug_init()` —— 调试通讯初始化
13. 主循环：按键扫描 + 目标位置设定 + 数据显示 + 上位机指令处理

## 五、控制原理（双闭环 PID）

系统为**串级双闭环**结构：

```
目标位置 ──► [外环：位置PID] ──► 目标电流 ──► [内环：电流PID] ──► PWM占空比 ──► 电机
                ▲                                  ▲                        │
                │                                  │                        ▼
           编码器位置反馈                      电流采样反馈                编码器/电流 采集
```

### 5.1 外环——位置环 PID（`g_location_pid`）

- 输入：目标位置 `SetPoint` 与编码器实际位置 `Feedback`。
- 输出：单极性目标电流（先由正负号确定电机转向，再取绝对值作为电流给定）。
- 输出限幅：`0 ~ 120 mA`（`MOTOR_MAX_TARGET_CURRENT`）。
- PID 参数：`L_KP = 0.18`，`L_KI = 0.00`，`L_KD = 0.08`。

### 5.2 内环——电流环 PID（`g_current_pid`）

- 输入：目标电流与实测电流反馈。
- 输出：PWM 占空比（单极性），最后输出到 `TIM1->CCR1`。
- 输出限幅：`0 ~ 8200`（`MOTOR_MAX_PWM_DUTY`）。
- PID 参数：`C_KP = 10.00`，`C_KI = 7.00`，`C_KD = 0.00`。

### 5.3 PID 算法

`pid.h` 中通过 `INCR_LOCT_SELECT` 宏选择算法类型：

- `0`：**位置式 PID**（本实验默认）
- `1`：**增量式 PID**

当前代码默认 `INCR_LOCT_SELECT = 0`，即位置式 PID（带积分累计项）。

### 5.4 控制时序

- TIM6 每 1 ms 触发一次中断。
- 每 5 ms 计算一次编码器速度（`speed_computer`）。
- 每 50 ms（`SMAPLSE_PID_SPEED`）执行一次双环 PID 控制（`motor_dual_loop_control_step`）。

### 5.5 编码器与位置换算

- 编码器线数 11 线，4 倍频（TI1+TI2）→ `ROTO_RATIO = 44` 计数/圈。
- 减速比 30:1 → `REDUCTION_RATIO = 30`。
- 电机输出轴转一圈对应的编码器计数 = `44 × 30 = 1320`。
- 位置目标每按一次 KEY0/KEY1 增减 1320（即电机转 1 圈），范围 ±6600（±5 圈）。
- 位置计算：`gtim_get_encode() = 当前计数 + 溢出次数 × 65536`。

## 六、关键模块说明

### 6.1 TIM1 互补 PWM（`dcmotor_tim.c`）

- 高级定时器 TIM1，PWM 模式 1，互补输出（OCy=PA8、OCyN=PB13）。
- 计数频率 168 MHz，ARR = 8399，PWM 周期 = 50 µs → **20 kHz**。
- 设置了死区时间寄存器 `BDTR`（`DeadTime = 0x0F`），避免 H 桥上下管直通。
- 方向切换：正转开启主通道 `TIM_CHANNEL_1`，反转开启互补通道 `TIM_CHANNEL_1N`。

### 6.2 TIM3 编码器接口（`dcmotor_tim.c`）

- 通用定时器 TIM3，编码器接口模式 `TIM_ENCODERMODE_TI12`（4 倍频）。
- 通道 1/2 分别接 PC6/PC7，输入滤波系数 10，更新中断记录溢出次数以扩展 32 位计数。

### 6.3 TIM6 定时中断

- 基本定时器 TIM6，预分频 83，自动重载 999 → **1 ms** 中断周期。
- 中断内完成编码器读取、速度/位置更新、以及定时触发的双环 PID 计算。

### 6.4 ADC + DMA（`adc.c`）

- ADC1，12 位，扫描 + 连续模式，3 通道（电压/温度/电流）。
- DMA2 Stream4、Channel0，循环模式，搬运至 `g_adc_value[3*1200]`。
- 转换完成回调中求平均、计算参考零电电流、一阶低通滤波（系数 0.4/0.6），滤除小于 20 mA 的漂移。
- 电流换算 `ADC2CURT = 3.3 / 4.096 / 0.12`；电压换算 `ADC2VBUS = 3.3 × 25 / 4096`。

### 6.5 电机驱动（`dc_motor.c`）

- 基本驱动：初始化、启停（SHDN 引脚）、方向、速度设置。
- `motor_pwm_set()`：根据正负号选择方向，输出 PWM 比较值。
- `speed_computer()`：滑动窗口（10 次）冒泡排序去极值求平均 + 一阶低通（0.48/0.52）滤波。
- `get_temp()`：通过 NTC 热敏电阻（10K、B=3380）计算温度，见公式注释。

### 6.6 上位机调试通讯（`Middlewares/DEBUG/debug.c`）

- 波特率 115200，帧头 `0xC5`，帧尾 `0x5C`。
- CRC16-Modbus（多项式 `0x8005`）校验，`EN_CRC = 1`。
- 支持上传电机状态、位置/编码器值、电流、电压、波形数据（`TYPE_USER_DATA`），以及下发运行/停机指令、调整 PID 参数（PID1/PID2）。
- 双环控制时，上位机 PID 助手（PID1 对应位置环、PID2 对应电流环）可实时在线调参。
- `DEBUG_ENABLE` 宏控制是否启用调试功能（当前为 1）。

## 七、构建与编译

项目使用 CMake + GCC ARM 工具链交叉编译，构建目录为 `build/`。

```bash
mkdir build && cd build
cmake .. -G Ninja
ninja
```

编译选项要点（`CMakeLists.txt`）：

- 目标：arm-none-eabi-gcc，`-mcpu=cortex-m4 -mthumb -mfpu=fpv4-sp-d16 -mfloat-abi=hard`。
- 宏定义：`USE_HAL_DRIVER`、`STM32F407xx`。
- 链接脚本：`STM32F407IGTx_FLASH.ld`。
- 自动生成 `.elf / .hex / .bin` 固件，并输出 `size` 统计。
- BSP 源文件排除 `lcd_ex.c`；HAL 源文件排除 `*_template.c`。

## 八、实验现象与操作

1. **LED0（红灯，PE0）** 以约 200 ms 周期闪烁，指示程序运行。
2. 按 **KEY0** 目标位置 +1320，电机正转 1 圈；上限 +6600（正转 5 圈）。
3. 按 **KEY1** 目标位置 -1320，电机反转 1 圈；下限 -6600（反转 5 圈）。
4. 按 **KEY2** 目标位置清零，电机回到初始位置 0。
5. **LCD** 实时显示：PWM 占空比、目标位置、实际位置、实际电流。
6. 上位机 PID 调试助手可远程设定目标位置、启停电机、观察电流/位置波形并在线整定 PID。

> 上电或复位后，建议等待约 2 秒待电流稳定后再按键启动；电机旋转/停止注意避震。

## 九、注意事项

1. 串口 1 波特率固定 115200 bps，若使用电脑端 PID 调试助手需与之匹配。
2. 本工程仅支持 MCU 屏（16 位 8080 并口），不兼容 RGB 屏。
3. 电源要求：驱动板用 12~60 V / 10 A 稳压或可调电源；开发板用 12~24 V / 1 A 直流电源（DC 接口），请按说明连接，谨防电机震动。
4. 双环控制时，外环（位置环）PID 参数调节幅度不宜过大，否则对整个响应曲线影响显著。
5. 限幅参数位于 `dcmotor_tim.c`：目标电流上限 `120 mA`、PWM 占空比上限 `8200`。
